# CardHolder

Тёмный каталог банковских карт: каталог, поиск, фильтры, сравнение до 3 карт, регистрация/вход, избранное и админ-управление каталогом.

## Важные ограничения

- Проект не является банком и не оформляет карты.
- Не добавляйте формы для номера карты, CVV, PIN или банковских паролей.
- Демонстрационные карточки и тарифы не являются актуальными банковскими предложениями. Перед публикацией замените их проверенными публичными данными и укажите источники/дату проверки.
- Никогда не публикуйте `service_role` ключ Supabase. На клиенте допустим только публичный anon/publishable key; доступ ограничивается RLS.

## 1. Что понадобится

- Node.js 20 или новее
- Аккаунт Supabase для базы данных и авторизации
- Аккаунт GitHub
- Аккаунт Vercel для публикации

## 2. Запуск локально

```bash
npm install
cp .env.example .env
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).

Пока Supabase не подключён, каталог работает в демонстрационном режиме. Регистрация, избранное между устройствами и администрирование требуют подключения базы.

## 3. Настройка Supabase

1. Создай проект в Supabase.
2. Открой SQL Editor.
3. Скопируй и выполни весь файл `supabase/schema.sql`.
4. В Project Settings → API найди Project URL и публичный anon/publishable key.
5. Скопируй `.env.example` в `.env` и заполни:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
6. Перезапусти `npm run dev`.

В Supabase Authentication можно включить подтверждение email. Для публичного сайта рекомендуется оставить подтверждение включённым и настроить Site URL / Redirect URLs.

## 4. Назначение администратора

После регистрации пользователя открой Supabase → Table Editor → `profiles`.
Найди строку своего пользователя и установи `is_admin = true`.
Не давай роль администратора обычным пользователям. После обновления страницы появится пункт «Администрирование», а также кнопки добавления, редактирования и удаления карточек.

## 5. Публикация в интернете

1. Загрузи папку проекта в новый приватный или публичный GitHub-репозиторий.
2. Войди в Vercel и выбери Add New → Project → импортируй репозиторий.
3. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
4. В Environment Variables добавь `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. Нажми Deploy.
6. После публикации добавь домен в Vercel → Settings → Domains. Vercel покажет DNS-записи, которые нужно внести у регистратора домена.
7. В Supabase Authentication → URL Configuration добавь адрес сайта в Site URL и Redirect URLs.

## 6. Домен

Варианты для проверки у регистратора (наличие не проверено):
- `cardholder.app`
- `cardholder.site`
- `cardholder.cards`
- `getcardholder.com`
- `cardholder.space`

Проверяй доступность и цену у регистратора перед покупкой. Домен — отдельная покупка; не вводи данные банковской карты на неизвестных сайтах.

## 7. Перед публичным запуском

- Заменить демонстрационные данные актуальными, проверенными данными и добавить дату проверки.
- Добавить страницу «О проекте», политику конфиденциальности и контакты оператора сайта.
- Проверить настройки email-подтверждения, RLS и админ-роли.
- Не собирать платёжные реквизиты и чувствительные банковские данные.
- Если сайт будет доступен пользователям из разных стран, уточнить применимые требования к конфиденциальности и обработке персональных данных.
